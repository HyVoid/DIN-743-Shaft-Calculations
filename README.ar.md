## التحقق من الإجهاد المتعب للأعمدة: نقاط الألم والحلول

| نقطة الألم في التصميم الهندسي | حل أداة DIN 743 (ما تتبعه) |
| :--- | :--- |
| **عوامل أمان متعب غير مؤكدة** | تحقق مؤتمت من **الحد الأدنى لمتطلبات أمان الإجهاد المتعب** (S_f) مقابل معايير المشروع الأساسية. |
| **تخمين حدود تحمّل المادة** | حساب ديناميكي لكيفية تأثير **اختيار المادة (إجهاد الخضوع، مقاومة الشد)** مباشرة على هوامش الأمان النهائية. |
| **أحمال متعددة المحاور معقدة** | تقييم متكامل لـ**عزوم الانحناء وأحمال الالتواء** المدمجة لتحديد مقبولية التصميم الإجمالية. |
| **تراكيز إجهاد غير مُكمَّمة** | تتبع فوري لتغيّرات الهندسة (مثل **أنصاف أقطار الأقواس والمجاري**) وأثرها على **حساسية الحزّ**. |
| **استخدام غير صحيح للإجهاد الاسمي** | انتقال مؤتمت من **الإجهاد الاسمي** الخام إلى **حدود تحمّل المكوّن** المصحَّحة (بإدماج عاملي الحجم وخشونة السطح). |
| **معايير إفراج غامضة** | تحديد واضح لـ«مقبول/مرفوض» يبيّن أي **مقاطع حرجة في العمود تستلزم إعادة تصميم** قبل الإفراج للتصنيع. |

## لماذا بنيت أداة تصميم الأعمدة الهندسية الميكانيكية هذه

نادرًا ما تكون حسابات DIN 743 صعبة بسبب الرياضيات. بل تصبح صعبة لأن عملية التفكير في التصميم الميكانيكي تتفتت بين ملاحظات مكتوبة بخط اليد، وصيغ معزولة، وحكم هندسي، وافتراضات مقاومة ساكنة غير موثَّقة.

رأيت مرارًا مراجعات تصميم وصل فيها المهندسون إلى استنتاجات مختلفة باستخدام الأحمال الدورية والقيود البُعدية نفسها تمامًا. ولم يكن الخلل حسابيًا في الغالب؛ بل كان تحليليًا.

نسي أحدهم عامل تركيز الإجهاد (Kt). واستخدم آخر الإجهادات الاسمية مباشرة مقابل حدود إجهاد المادة دون التصحيح اللازم. ونسخ ثالث صيغة من جدول قديم دون التحقق من أن افتراضات التحميل الديناميكي الأساسية ما زالت سارية.

وكانت النتيجة متوقعة:

* صارت التصاميم الميكانيكية المتحفظة مكلفة بلا داعٍ.
* اجتازت نماذج الأعمدة الحدّية مراجعة ضبط الجودة دون أن يُلاحظ أحد.
* أصبح التحقق الإنشائي معتمدًا على المعرفة الفردية المتوارثة بدلًا من عملية تنظيمية قابلة للتدقيق.

يحوّل هذا المصنّف المنطق الكامن في معيار DIN 743 إلى منتج. فبدلًا من معاملة التحقق من إجهاد العمود كتمرين حسابي لمرة واحدة، يحوّل المعيار إلى إطار قرار قابل لإعادة الاستخدام.

### مثال عملي: الإجهاد الاسمي مقابل الإجهاد المصحَّح

**قبل**
يقارن مصمّم CAD إجهاد انحناء اسميًا قدره 185 MPa مباشرة بحدّ إجهاد مادة قدره 210 MPa ويستنتج أن التصميم مقبول.

**بعد**
تطبّق أداة الحساب تلقائيًا تأثيرات الهندسة، وحساسية الحزّ، وتصحيحات الحجم، وعوامل التأثير السطحي. فينخفض حدّ التحمّل المصحَّح إلى 168 MPa.

ويتغيّر الاستنتاج فورًا:

```text
Original Decision:
PASS

Corrected Decision:
FAIL → Redesign Required
```

### ثلاثة فِخاخ تصطاد حتى المهندسين الميكانيكيين المخضرمين

---

#### الفخ 1: مقارنة الإجهاد الاسمي مباشرة بحدود إجهاد المادة

اتُّخذ قرار:

```
185 MPa < 210 MPa
PASS
```

الافتراض الخاطئ:

الإجهادات الاسمية تمثّل سعة الإجهاد المتعب الفعلية.

سبب الخطأ:

يجب تعديل حدود تحمّل المادة وفق تأثيرات المكوّن.

النهج المصحَّح:

```
σWK = (σW × Kd × KF) / β
```

النتيجة المصحَّحة:

```
Corrected endurance limit:
168 MPa

185 MPa > 168 MPa

FAIL
```

<details>
<summary>مرجع الصيغ</summary>

```excel
=(Sigma_W * Kd * KF) / Beta
```

</details>

---

#### الفخ 2: تجاهل تأثيرات الهندسة

القرار:

زيادة قطر العمود قليلًا.

الافتراض الخاطئ:

التغيّرات الهندسية الصغيرة تأثيرها مهمل.

سبب الخطأ:

الأقواس والمجاري تغيّر تركيز الإجهاد تغييرًا جوهريًا.

النهج المصحَّح:

تقييم عاملي α وβ.

النتيجة:

نصف قطر قوس أكبر حسّن أمان الإجهاد المتعب بتقليل حِدّة الحزّ.

<details>
<summary>مرجع الصيغ</summary>

```excel
Beta = 1 + q*(Alpha-1)
```

</details>

---

#### الفخ 3: معاملة الانحناء والالتواء بشكل مستقل

القرار:

كلا عاملي الأمان يتجاوز الحدود منفردًا.

الافتراض الخاطئ:

القبول المنفرد يضمن قبول المنظومة.

سبب الخطأ:

التحميل المدمج هو ما يحكم أداء الإجهاد المتعب.

النهج المصحَّح:

استخدام تقييم أمان مدمج.

النتيجة:

حالات «مقبول» منفردة صارت «مرفوض» مدمجة.

<details>
<summary>مرجع الصيغ</summary>

```excel
S=(Sb*St)/SQRT(Sb^2+St^2)
```

</details>

### سيناريو توضيحي

يُقيَّم مقطع ساق صمام باستخدام:

| المعامل                |        القيمة |
| ---------------------- | -----------: |
| المادة                 |       17-4PH |
| القطر                  |        40 mm |
| نصف قطر القوس          |         2 mm |
| عزم الانحناء           | 450,000 N·mm |
| عزم الالتواء           | 180,000 N·mm |
| عامل الخدمة            |         1.25 |
| عامل الأمان المطلوب    |         1.50 |

الحسابات الوسيطة:

```text
Wb = πd³/32
Wp = πd³/16

σb = Mb×KA/Wb
τt = T×KA/Wp
```

وبعد تطبيق:

* حساسية الحزّ،
* تصحيحات الهندسة،
* تأثيرات الحجم،
* عوامل التأثير السطحي،

يصبح عامل أمان الإجهاد المتعب المدمج:

```text
S = 1.38
```

التفسير:

```
Required:
S ≥ 1.50

Actual:
S = 1.38
```

التوصية:

زيادة القطر، أو تعديل الهندسة، أو تقليل الأحمال، أو إعادة النظر في اختيار المادة قبل الإفراج.

دلالة القرار:

لا ينبغي إحالة العمود إلى التصنيع في ظل افتراضات التصميم الحالية.
